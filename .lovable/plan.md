# استكمال الصفحات التشغيلية الست

## الهدف
تطوير الصفحات الست المعتمدة باستخدام البيانات والعمليات الموجودة، وتوحيد قائمة الموردين مع مصدر إضافة المورد الحالي، دون تعديل قاعدة البيانات أو كسر الصلاحيات.

## النطاق
- طلبات الصيانة: تحسين العرض والإجراءات الحالية مع الحفاظ على البحث والفلاتر والتقويم والتصدير والترقيم.
- تفاصيل الطلب: ربط المعلومات وسير العمل والفواتير والمواد والمرفقات بالسجلات الموجودة، وإزالة حالات «قيد التطوير» حين تتوفر بيانات فعلية.
- الخطط الوقائية: تحسين حالات التحميل والخطأ والحفظ والتوليد، مع إبقاء حجز التشغيل وبوابة إنشاء الطلب الحاليين.
- استيراد العقارات: تدقيق مسار CSV/XLSX والمعاينة والتحقق والتكرارات والتقدم، مع استخدام مخطط البيانات الحالي فقط.
- عقود الصيانة: تحسين البحث والفلاتر والحالات والإحصاءات والنموذج عبر الجداول الحالية.
- الموردون: قراءة وإضافة وتحديث الموردين عبر `service_providers` ومطابقة العرض لحقولها الفعلية؛ لا ترحيل ولا إنشاء جدول.

## التحقق
مراجعة التغييرات على مستوى TypeScript واختبار المسارات المتاحة، ثم مراجعة أحدث سجل بناء ومعاينة تدفق الموردين والاستيراد والعقد والطلب حيث تسمح الجلسة والصلاحيات.

## قرارات تقنية
- إعادة استخدام الجداول والـ hooks والبوابات الحالية فقط؛ لأن المطلوب إكمال الصفحات دون تغيير قاعدة البيانات.
- الحفاظ على صلاحيات RLS ومصادر التفويض الحالية، وعدم استبدالها بتصفية واجهة.
