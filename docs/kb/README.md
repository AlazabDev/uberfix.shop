## قواعد ثابتة لا تُخالف

1. كل طلب صيانة يدخل النظام عبر باب واحد: `POST /functions/v1/api`.
2. `workflow_stage_v2` هو مصدر الحقيقة للمرحلة، ولا يُكتب مباشرة أبدًا — فقط عبر `fn_transition_request_stage`.
3. المفاتيح تُخزَّن مُهشَّرة (SHA-256) في `api_consumers`، ولا تُطبع ولا تُوثَّق بقيمتها.
4. لا تعديل يدوي على `supabase/migrations/` — التغيير عبر أداة الترحيل فقط.
5. الامتثال لقانون حماية البيانات المصري 151/2020: لا تخزين بيانات دفع، وتعمية الهواتف في السجلات.
6. المراسلة التشغيلية بالعربية، والواجهة RTL أولًا.
