# Meta Review — Human Agent Permission Video Script

**App**: UberFix — Maintenance Service Platform
**Domain**: https://uf.alazab.com
**Recording duration**: 3–4 minutes (no audio required)
**Resolution**: 1920×1080, screen recorder, mouse cursor visible

## Use-case statement (read aloud or pin as caption)

> "UberFix support agents use Meta Inbox tools to reply to maintenance
> customers within a 7-day window for **customer service only** —
> dispatching technicians, sharing visit ETA, and resolving service
> issues. No promotional or marketing content is sent outside the
> standard 24-hour window."

## Scenes

1. **Identity (0:00 – 0:15)**
   Open `https://uf.alazab.com/meta-review`. Show the platform name,
   the Human Agent section, and the policy paragraph.

2. **Login as a human support agent (0:15 – 0:35)**
   Sign in with a `support` / `manager` role account. Show the agent
   avatar and full name in the top header to prove this is a real
   human user, not a bot.

3. **Unified inbox (0:35 – 1:35)** ⭐
   Navigate to `/wa-hub` (WhatsApp + Instagram + Facebook DMs).
   - Show the list of inbound conversations from real customers
     (blur phone numbers if needed).
   - Highlight a conversation older than 24 hours — show the
     "Last customer message: X days ago" badge.
   - Open the conversation and demonstrate the **Assign to agent**
     control; select the logged-in agent by name.

4. **Live human reply (1:35 – 2:15)**
   Type a fresh, personalized reply slowly (so it is visibly typed,
   not templated):

   > "أهلاً أ. أحمد، تم إرسال الفني محمد إليك الساعة 4 عصراً،
   > هل الموعد مناسب؟"

   Press send. Show the message appearing in the thread with the
   agent name and timestamp.

5. **Conversation history (2:15 – 2:45)**
   Scroll up to show the full multi-day message history with each
   outbound message tagged with the agent's name.

6. **Create a maintenance request from chat (2:45 – 3:15)**
   Click **Create maintenance request**, show the auto-filled form,
   submit, and reveal the unified serial number
   `UF/MR/YYMMDD/NNNN`.

7. **Policy & closing (3:15 – 3:30)**
   Return to `/meta-review` and zoom on the Human Agent policy block:

   > "Human Agent access is used exclusively for post-sale maintenance
   > support within the 7-day customer-service window. No marketing
   > messages are sent outside the 24-hour window."

## Pre-recording checklist

- [ ] At least 2–3 sandbox conversations older than 24 hours
- [ ] Agent profile has a real name and avatar set
- [ ] `/wa-hub` shows "X days ago" badge on conversations
- [ ] Assign-to-agent control is visible and functional
- [ ] `/meta-review` shows the dedicated Human Agent block
- [ ] Screen recorder set to 1920×1080, cursor highlights enabled
- [ ] UberFix watermark + recording date overlaid on the final clip
